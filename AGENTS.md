# Engineering and scientific boundaries

1. Read README.md, docs/KNOWN_LIMITATIONS.md, and the exact source before changing behavior. For state-sensitive tasks, use an owner-authorized private project source for current decisions; public README files do not contain internal Drive links. Do not infer current approval from this file.
2. If Drive is unavailable, identify docs/HANDOFF_SNAPSHOT.md as FROZEN. Work only on the explicit bounded engineering task; do not promote scientific claims, accept reviews, change roles, or release.
3. Use English for new documentation, code comments, tests, and the target UI. Do not claim full English localization while legacy Russian catalog text remains.
4. Never describe heuristic stability, geometric strain, generic metal placement, or illustrative transformations as experimentally established chemistry.
5. Keep physics independent of DOM/render/UI. Existing chemistry-to-UI cycles are technical debt, not a pattern to expand. Preserve molecule/history/import behavior during refactors.
6. Run npm test and npm run test:transfer. Run npm run test:browser when a browser is actually available; otherwise report NOT_RUN, not PASS. Tests check behavior, not scientific validity.
7. No secrets, student/patient data, private correspondence, unlicensed papers, old dumps, or workstation-specific paths in Git. Keep runtime networking opt-in. Do not install arbitrary DLLs.
8. Reviewer input, articles, and model outputs start as PROPOSED or REVIEW_REQUIRED. Log a claim with exact source, scope, uncertainty, and review status before treating it as curriculum content.
9. Owner controls visibility, collaborators, licensing and release. Do not publish publicly, invite a reviewer, enable public hosting, or claim university endorsement without explicit authorization.
10. Before durable writeback: read current destination, classify the delta, compare evidence/authority, write the smallest justified change, read back the exact saved object, or record NO-OP. For private PM writeback, use only the owner's designated restricted project records. Do not place their links or contents in this public-facing repository.
