Audio library for the chemistry sandbox
======================================

License: CC0-1.0 for generated files in this folder.

These short WAV effects were procedurally generated for this project, not copied
from third-party libraries. That avoids attribution ambiguity and keeps the
offline `file://` app self-contained.

External libraries considered for future import:
- OpenGameArt CC0 UI sounds: https://opengameart.org/content/ui-sounds-0
- Kenney audio assets, usually CC0: https://www.kenney.nl/assets

Before importing external MP3/WAV files, keep a copy of the exact license and
source URL next to the file.
