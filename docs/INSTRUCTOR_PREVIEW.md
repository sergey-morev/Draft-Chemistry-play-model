# Controlled instructor preview: four molecular sketches

**Exploratory prototype, partial English.** This is a private engineering walkthrough for a possible formative review, not an invitation or a published site. It is not scientifically validated, accepted for student use, or suitable for laboratory or clinical decisions. An instructor's assessment and any external access require separate owner decisions.

At desktop width, use the **Substance** field and **Reference** button. On a phone, the top **Reference** menu opens the guide; **Journal** opens and closes the process log. **Library** offers element selection, and the canvas supports placement and editing. **Undo** and **Redo** reverse and restore edits. These examples use existing catalog mappings and simplified 2D drawings:

1. Enter `H2O`. The current water entry shows one explicit O atom and implicit H atoms, so the diagram is not a full atom drawing. Open **Reference** for the model explanation.
2. Enter `CO2`. The current catalog mapping shows three explicit atoms and two C=O bonds. Compare its drawn connectivity with the water entry; a molecular formula alone does not uniquely identify a structure in general.
3. Enter `glucose`. Open the inspector and general reference. This is a catalog-mapped schematic; the formula `C6H12O6` alone does not prove glucose identity, ring form or stereochemistry. Some inherited catalog descriptions are still Russian and are labeled as untranslated.
4. Enter `ethanol`. Compare its catalog-mapped connectivity and reference with glucose. Some inherited uses remain Russian, visibly labeled as untranslated.

The displayed stability percentage is a **rule-based heuristic**, not measured thermodynamic stability. The layout and strain display are schematic estimates, not validated physical energies. Reaction controls are illustrative and do not predict chemical outcomes. Coordination, isotope, radiochemical and biomolecular examples await separate scientific review. RDKit and PubChem are optional external checks and may load resources or send a query over the network; none is required for this local walkthrough.

This walkthrough can support formative feedback on usability, clarity and which scientific claims need verification. It does not request endorsement.
