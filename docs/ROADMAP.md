# Gated transition plan

All implementation packages below are PROPOSED until scheduled by the owner. Publication remains separately gated.

| Package | Deliverable | Gate / evidence |
| --- | --- | --- |
| WP-00 | Private repository, full preserved archive, source manifest and cold-start packet | Exact remote commit/tree checked; no laptop dependency for source retrieval |
| WP-01 | English locale layer for controls, inspector, errors, reference and terminology | English UI acceptance, Unicode/overflow/accessibility tests; Russian fallback not advertised as completed translation |
| WP-02 | Pure graph/domain commands, separate analysis and UI adapters | No UI imports in approved domain boundary; graph/history regression fixtures |
| WP-03 | Instructor-defined MVP and student mode | Written curriculum scope; hide nuclear/medical/proxy/game-only actions by default |
| WP-04 | Reviewed element/isotope/substance data and provenance schema | No invented masses; unit/source/license checks; exact graph and stereochemistry records |
| WP-05 | Authoritative parser and edited-graph validation | Pinned engine version; supported/unsupported grammar fixtures; clear unknown/error states |
| WP-06 | Source-backed reaction exercises | Atom/charge/mass balance, conditions and bounded explanation; instructor accepts each case |
| WP-07 | Reviewed coordination and biomolecule representations | Distinguish sketch, graph, formula, oxidation state and coordination; no unsupported biological claims |
| WP-08 | Reproducible browser/CI checks, offline build, security/privacy and accessibility | Fresh cloud run, screenshots, hashes, network behavior, no secrets or student records |
| WP-09 | Limited instructor-supervised pilot | Exact reviewed commit/content set; feedback and acceptance record |
| WP-10 | Public-readiness review | License/asset/history audit, documentation, known issues, owner release authorization |

Suggested first bounded engineering task: WP-01 terminology inventory and UI string extraction, while WP-03 scientific scope is agreed. Do not silently rewrite chemical behavior during translation.
